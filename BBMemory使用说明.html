快速开始

  1. 在 SillyTavern 进入任意角色聊天，打开右侧扩展设置，展开 BB-Memory v9.3.3，确认“启用 BB-Memory”已勾选。
  2. 如果是旧聊天或已有存档，先点 手动提取，可以输入楼层范围，例如 0-80；留空会提取最近 8 轮。
  3. 如果是新角色长篇开局，建议先用 tools/bbmemory-initializer.html 外置工具从角色卡、世界书和聊天记录生成导入 JSON，再到“记忆管理”里导入。
  4. 正常聊天时，BB-Memory 会在生成前检索相关记忆。命中的内容会显示在“命中条目”和悬浮按钮的命中视图里。
  5. 阶段结束后点 备份 或在“存档”页保存槽位；切换设备时，文本走聊天元数据备份，向量走“云端向量槽”。

推荐默认用法

不确定怎么调设置时，可以先只配置 AI 提取 API，然后使用默认阈值。v9.3.3 会保留原有增量去重，并用链式聚类整理渐进细化型重复；拆分和删除默认必须确认。

手动提取先跑一遍 半自动确认更稳 里程碑保持克制 常备份再做批量操作
提示：BB-Memory 只负责整理和注入记忆，不会替代模型本身的理解能力。记忆质量主要取决于提取 prompt、上下文范围和后续人工整理。

运行顺序与工作原理

这一节解释 BB-Memory 在聊天时到底什么时候动、会把什么提示词发给 AI、AI 应该返回什么、重复或失败时怎么处理。你可以把它当作“开关和流程对照图”。

自动提取开启后：从聊天楼层到保存记忆
顺序发生什么相关开关
1. AI 回复完成SillyTavern 触发消息接收事件。BB-Memory 会等待约 2.5 秒再处理，避免刚生成完就立刻改楼层状态。启用 BB-Memory、启用 AI 自动提取
2. 同步短期窗口系统从聊天末尾往前数，把最近的若干个未处理 exchange 留在聊天里，窗口外更早的完整 exchange 标记为“待提取”。上下文保留窗口
3. 判断可提取 exchange每个 exchange 由“最近一条用户消息 + 后续 AI 回复”组成；开场白会并入第一个 exchange 的上下文。已处理过、已跳过、元对话标记的楼层不会重复进入队列。标记消息、楼层可见
4. 读取 AI 回复内容如果 AI 回复里有选中的 XML 风格标签，例如 <content>、<context>、<status>，提取器优先只读取这些标签内容；没有命中标签时读取普通回复文本。AI 提取读取标签、自定义读取标签
5. 调用提取 APIBB-Memory 构建“合并提取提示词”，要求模型只返回 JSON 对象；API 可以走酒馆主 API，也可以走自定义 OpenAI 兼容 API。API 模式、API 预设、自定义 API 端点
6. 解析返回结果正常返回会被解析为 NPC、物品、里程碑、地点、时间线、记忆数组；如果返回 META_DIALOGUE，该楼层会被视为纯元对话并跳过。提取元对话防护、提示词模板
7. 保存或等待确认主动确认模式会先进入候选审核；半自动和全自动会直接保存。保存时 NPC、物品、里程碑、地点、时间线走 upsert，普通记忆按去重逻辑处理。提取确认模式、确认通知方式
8. 标记楼层成功保存后，用户楼层、AI 楼层和开场白上下文会标记为已提取，并按显示模式隐藏或显示。失败时楼层保留为待处理，悬浮菜单可重试。楼层可见、调试日志
9. 并行抓取场景细节主提取同时对该层 AI 回复做轻量细节抓取，保存交通、衣着、在场者等第五柱内容；副调用失败不会污染主提取状态。实时记忆、抓取范围
10. 后台整理与维护新增计数达标后，AI 整理师在后台聚类重复候选；时间线总结也会按原设置刷新。AI 记忆整理、时间线总结
默认“上下文保留窗口”为 3。由于最新 AI 回复会额外保留给用户检查，通常到第 5 条 AI 回复出现后，最早的一组用户 + AI 回复才会开始自动提取；之后每新增一条 AI 回复，就会继续把更早的一组送入队列。
BB-Memory 会发什么提示词，AI 应该返回什么

实际提示词可以在“自定义设置 -> 提示词模板”中查看和编辑。自动提取和手动提取共用“合并提取总模板”。下面是结构化后的简化示意，不是完整原文。

部分内容作用
System prompt要求模型扮演 JSON 格式的记忆提取助手，只输出纯 JSON 对象，不要解释。降低模型输出 markdown 或闲聊文本的概率。
元对话防护要求识别 OOC、工具说明、格式修复、纯系统指令等非 RP 内容。如果整段都是元对话，模型可返回 META_DIALOGUE。
核心原则判断哪些信息值得长期保存，例如关系变化、承诺、伏笔、状态变化、世界观事实。避免把每句普通寒暄都写成记忆。
提取维度要求模型分别考虑记忆、NPC、物品、里程碑、地图地点、时间线。让一次 API 调用覆盖多个数据支柱。
故事日历和风格偏置插入当前聊天的历法说明，以及日常陪伴、正剧叙事或自定义偏置。让故事时间和提取侧重点更符合当前 RP。
当前对话填入本次 exchange 的用户消息和 AI 回复；手动提取时用户消息位置会放入整段上下文，AI 回复位置显示“见上下文”。这是模型实际读取的剧情材料。
返回格式示意
{"memories":[],"npc":[],"items":[],"milestones":[],"locations":[],"timeline":[]}

其中 memories 是普通记忆，npc 是 NPC 档案，items 是物品，milestones 是重大节点，locations 是地图地点，timeline 是持续叙事线。任一数组都可以为空。

重复、相似、失败会怎么样
情况处理方式你会看到什么
同一楼层重复触发BB-Memory 会用用户消息 + AI 回复计算 exchange hash。已处理 hash 不会再次调用提取 API，只会补齐已提取标记和隐藏状态。楼层状态变为已提取，不会新增重复记忆。
纯元对话模型返回 META_DIALOGUE 或用户手动标记后，系统会把该 exchange 标为跳过并加入已处理集合。toast 或活动记录提示“纯元对话跳过”。
NPC / 物品 / 地点重名保存时会按名称或现有 ID upsert，尽量更新旧条目，而不是新增同名条目。管理器里看到旧条目内容被补充或更新。
普通记忆高度相似增量去重仍会在达到合并阈值时更新旧记忆；同一天内只有时刻差异不再额外扣分，跨日期仍视为冲突。明确重复会直接合并；中等相似项保留审核标记。
渐进细化型重复AI 整理师从本批新增条目召回候选，以默认 0.65 建边并做链式聚类，让 AI 一次看到整组后重写为最终态，不用“[补充]”拼接。侧边栏显示进度与摘要；高风险操作进入确认面板，并可撤销。
普通记忆中度相似相似度达到降权阈值但不足合并时，新记忆仍可保存，但重要性会降低。条目可能以较低优先级参与后续检索。
没有开启向量普通记忆无法做语义去重，只能依赖标题、标签、人工整理和体检。可能出现相似条目，建议定期运行记忆体检。
API 失败或 JSON 解析失败本次 exchange 不会标记为成功提取，失败楼层会记录下来，方便之后重试。toast、错误弹窗或活动记录显示失败原因。
生成回复前：从记忆库到注入 prompt
顺序发生什么相关设置
1. 用户发送消息BB-Memory 的生成拦截器读取最后一条用户消息。如果扩展关闭或当前聊天没有数据，会清空注入并放行。启用 BB-Memory
2. 加载所有数据读取 NPC、物品、里程碑、时间线、记忆、实时记忆、线索板、地图，并尝试加载压缩向量。实时记忆、语义向量、线索板注入
3. 自动维护静默执行轻量维护，例如积灰和可压缩项检查。维护模式、维护阈值
4. 计算查询向量如果启用语义向量，会为用户最新消息请求一次 embedding；失败则降级为关键词检索。启用语义向量检索
5. 分支检索NPC、物品、里程碑、时间线、地图、线索板、普通记忆分别检索和筛选。普通记忆综合关键词、embedding、近期性、层级分打分。最大检索数、最低相关分、各类注入上限
6. 实体展开如果用户消息命中某个实体名，会额外拉出相关记忆，避免只注入实体卡而漏掉关联经历。最大检索数、Token 预算
7. 长期预算裁剪按 Token 预算和预算模式裁剪长期区块。核心、永恒、常驻内容优先保留。Token 预算、Token 预算模式
8. 追加实时细节仍生效或待结算的第五柱绕过检索无条件追加，但严格受独立条数与 token 双上限保护。实时注入上限
9. 写入 SillyTavern prompt用注入模板包裹整理后的内容，通过 setExtensionPrompt 写入生成上下文。注入模板
10. 记录命中实际注入的长期条目会增加命中计数；实时记忆不参与向量命中或层级升降。升级/降级阈值、多样性限制
开关怎样改变流程
开关或数值影响的流程关闭或调低后会怎样
启用 AI 自动提取控制 AI 回复后是否自动进入提取队列。不会自动提取，但仍可手动提取和注入已有记忆。
上下文保留窗口决定旧楼层多早进入自动提取。调大更安全，重 Roll 不易误提取；调小更快沉淀记忆。
并行提取数决定一次处理多少个待提取 exchange。调低更稳更慢；调高更快但更吃 API 限速。
提取确认模式决定提取结果是否先给用户审核。主动确认最可控，全自动最快。
AI 提取读取标签决定提取器读取 AI 回复全文还是只读特定标签。关闭或不命中标签时，会回退读取普通回复文本。
启用语义向量检索影响检索、去重、地图地点匹配和重建索引。关闭后依赖关键词、标签和模糊搜索。
启用语义去重影响保存新普通记忆时是否做相似合并。关闭后相似记忆会更容易并存，需要人工体检。
启用线索板注入决定玩家推理是否进入生成 prompt。关闭后线索板仍保存，但 AI 不会看到。
启用时间线总结决定持续叙事线是否注入，以及自动提取后是否尝试后台刷新。关闭后只靠里程碑和普通记忆维持长篇脉络。
启用 AI 记忆整理决定新增计数达标后是否在后台聚类整理重复组。关闭后仍保留增量去重，也可手动全库整理。
启用实时记忆决定是否抓取、注入并自动结算当前场景细节。关闭后已有第五柱数据保留，但不再抓取或注入。
Token 预算模式决定常驻内容是否可以超出总预算。严格总量更省上下文，但可能截掉一些常驻信息。

入口位置与按钮用途

初始化记忆

提示你使用外置 HTML 初始化工具。适合从角色卡、世界书、旧聊天、旧 JSON 备份生成第一批结构化记忆。

记忆管理

打开完整管理器，包含记忆列表、实时记忆、存档槽、时间线、仪表盘、分类、归档仓库。实时页可编辑、晋升、留档/恢复、立即结算和撤销。

使用说明

打开当前页面。用户不知道按钮在哪里时，优先看本页顶部的面板示意图。

记忆维护

检查积灰物品、状态变化、可压缩里程碑、低优先级 NPC 等，按建议保留、升格、降格、压缩或删除。

手动提取

从当前聊天上下文提取 NPC、物品、里程碑、时间线、地图地点和记忆。可输入楼层范围，也可在弹窗里点“换楼提取到最新”。

标记消息

把最后一条 AI 消息标记为元对话或取消标记。标记后它仍可显示在聊天里，但提取时会跳过，适合 OOC、系统提示、格式修复。

楼层可见

切换已提取楼层的显示状态。它主要用于临时检查，真实隐藏状态仍由 SillyTavern 原生消息标记保存。

刷新时间线

读取已有里程碑和旧时间线，请 AI 重新整理为持续叙事线，例如主线、感情线、支线和世界观线。

换楼刷新

开新聊天后使用，把已有条目的来源楼层标记为旧聊天，避免楼层号和新聊天冲突。

线索板

把记忆、NPC、物品、里程碑、地图地点摆成节点，手动连线表达玩家推理。启用注入后，AI 会看到这些推测。

世界地图

管理地点、地区、层级关系、路径和物品位置。地图地点会参与检索和注入。

备份 / 恢复

把当前聊天的文本记忆和向量引用保存到聊天元数据，或从聊天元数据恢复。大存档建议用管理器 JSON 导出。

BB-Memory 记录什么

记忆条目

普通长期记忆，分为事件、情感、习惯、事实。层级有瞬时、稳定、核心、永恒；归档条目会保留但不参与检索。

NPC 档案

记录角色身份、性格、外貌、位置、关系、故事时间。等级为核心、重要、配角、背景。

物品栏

记录关键物品、装备、线索物、消耗品和背景物品，包含持有者、位置、状态、数量等。

里程碑

记录真正重要的剧情节点，例如关系质变、伏笔出现、冲突解决、阶段结束。可以常驻注入或仅相关时注入。

时间线

把多个里程碑整理成持续故事线，例如“主线调查”“感情线”“王国政变”。时间线可 ongoing、paused、ended 或 resident。

实时记忆（第五柱）

保存交通、衣着、座位、在场者、临时偏好和随手物位置。它不做向量检索，会在仍生效时无条件注入；结算后可晋升长期库或留档。

地图与线索板

地图负责空间关系，线索板负责玩家推理。它们是支撑系统，会与五柱一起参与管理和注入。

注入时会发生什么
阶段说明你能观察到什么
读取数据从 localforage 读取 NPC、物品、里程碑、时间线、地图、线索板、长期记忆和实时记忆。调试日志开启时可在控制台看到读取与检索信息。
相关性检索综合关键词、向量相似、实体命中、层级加成、近期性等维度打分。侧边栏“命中条目”和悬浮按钮命中视图会显示本轮命中。
预算分配按 Token 预算和预算模式裁剪内容。核心、永恒、常驻内容通常更优先。如果内容过多，低优先级条目会被截断或不注入。
写入 prompt最终文本通过 SillyTavern 的扩展 prompt 注入到生成上下文。AI 回复会更容易延续旧剧情、地点、物品和关系。

常用工作流

新聊天从零开始

启用扩展后正常聊天。每隔一段剧情点“手动提取”，检查“记忆管理”里的新增条目。里程碑只保留大转折，普通流水账放进记忆条目即可。

旧聊天补齐记忆

点“手动提取”，输入楼层范围，或点“换楼提取到最新”。提取完成后用“记忆管理”搜索、删除重复项，再点“刷新时间线”。

长篇多分支

在“存档”页为不同路线建立槽位，例如“主线”“if线A”。切换前保存当前槽，加载另一个槽会覆盖当前聊天的 BB-Memory 数据。

跨设备同步

点“备份”保存文本和向量引用到聊天元数据；在管理器“存档”页上传云端向量槽。新设备先恢复文本，再加载云端向量。

剧情推理

在线索板添加节点，把“钥匙”“失踪 NPC”“时间矛盾”等连起来。低信心线索可以保留为推测，AI 会收到这些推理但不必全部确认。

记忆过多时

先跑“记忆维护”和“记忆体检”，再在管理器里归档或删除低价值条目。把 Token 预算模式切到严格总量可以减少注入挤占。

楼层状态统计待提取、已提取、未提取楼层。旧聊天补记忆时重点看这里。
云备份不再内联向量提示当前文本备份不会把 embedding 大块塞进聊天元数据。向量同步请用“存档”页的云端向量槽。
AI 自动提取
设置代表什么建议
启用 AI 自动提取AI 回复后自动把超出保留窗口的完整 exchange 送去提取。初期建议关闭或半自动；确认风格稳定后再开启。
调试日志在浏览器控制台输出更详细的提取、检索和错误信息。排查问题时开启，日常关闭。
API 模式主 API 使用当前酒馆生成接口；自定义 API 使用你填写的 OpenAI 兼容端点。想让提取不干扰主聊天时用自定义 API。
提取确认模式主动确认会弹出候选；半自动默认更稳；全自动直接保存结果。长篇正式档推荐半自动，批量补档可临时全自动。
确认通知方式主动确认时使用浮动弹窗或 toast 通知。需要逐条审查用浮动弹窗。
上下文保留窗口保留最近 N 个未提取 exchange，超过窗口后才入队提取并隐藏。默认 3 较稳；频繁重 Roll 可调大。
AI 提取读取标签如果回复含 <content>、<context> 等标签，只读取选中标签里的内容。使用结构化回复模板时很有用；无标签时会回退普通文本。
自定义读取标签追加自定义 XML 风格标签名，例如 time,scene。和你的角色卡输出格式一致即可。
并行提取数同时发送多少个 exchange 提取请求。默认 2；API 限速严格时调成 1。
更新回滚快照保留楼层数AI 更新旧条目时，为最近 N 楼保存回滚快照。默认 10；想减小存档体积可调低或设 0。
API 预设保存提取 API 和 Embedding API 配置，并快速切换。常用多个供应商时很方便；API Key 不会随设置导出。
自定义 API 端点 / Key / 模型OpenAI 兼容的 chat completions 地址、密钥和模型名。端点需是 http/https；填完先点“测试连接”。
提取风格调整提取侧重：自动、日常陪伴、正剧叙事或自定义偏置。恋爱日常用“日常陪伴”，悬疑长篇用“正剧叙事”。
自定义风格偏置补充你想优先记录的内容类型。写具体偏好，例如“优先保留未说出口的承诺和情绪变化”。
语义向量
设置代表什么建议
Embedding 预设复用 AI 提取预设中的 embedding 配置。保存预设后可一键同步两组 API 配置。
启用语义向量检索用 embedding 相似度辅助检索，能匹配同义表达。API 可用时建议开启，长篇记忆收益明显。
Embedding API 端点 / Key / 模型OpenAI 兼容 embedding 接口配置。默认模型名为 text-embedding-3-small；填完先测试连接。
重建语义索引为已有 NPC、物品、里程碑、记忆、时间线和地图重新生成向量。更换 embedding 模型后必须重建。
启用语义去重提取时用向量相似度合并或减少重复条目。建议开启；如果你想保留非常细碎差异，可临时关闭。
AI 记忆整理
设置代表什么建议
启用 / 触发模式任一柱、全部柱达标或仅手动时启动整理。默认任一柱达标。
各柱触发阈值NPC、物品、里程碑、时间线和记忆各自新增多少条后触发。高频柱可调高，设 0 可排除该柱。
每条召回数 / 聚类阈值决定候选范围与链式建边松紧。默认阈值 0.65 专门用来捕获渐进细化链。不确定时保持默认，不要照 0.85 合并线调高。
单次最大组数一次最多把多少个候选组交给 AI。默认 8，限速严格时调低。
四类操作授权合并、重写、拆分、删除分别选择直接执行、执行并提醒或必须确认。默认合并/重写提醒，拆分/删除确认。
撤销深度保留最近几次整理快照。默认 3；批量整理前仍建议备份。
时间冲突粒度按日期、精确字符串或关闭时间惩罚。默认按日期；同日时刻差异不扣分，跨日期仍扣分。
实时记忆（第五柱）
设置代表什么建议
启用实时记忆 / 启用抓取总开关与是否产生新的短期场景细节。默认开启；已有数据在关闭时仍保留。
抓取范围 / 场景前 N 层每层抓取，或只抓每个场景开始的前几层。想降低副 API 调用可选前 N 层。
单层最多细节一次轻量抓取最多保存几条。默认 5。
注入条数 / token 上限第五柱独立于长期预算的双硬上限。默认 15 / 300；不要取消上限。
TTL / 生效容量 / 场景切换三类自动待结算触发器。默认 12 层 / 40 条 / 开启。
结算时机自动调 API，或只标待结算并等“立即结算”。API 不稳定时选手动。
晋升写入方式AI 判断有长期价值时直接写入，或写入前确认。风险敏感时选确认。
结算里的 discard 只把条目标为“已结算”并停止注入，不会立即删除。未晋升留档超过容量上限两倍后，系统才机械修剪最旧部分。
注入设置
设置代表什么建议
最大检索数普通记忆条目每轮最多注入多少条，不包含 NPC、物品等独立上限。默认 10；模型上下文短时调小。
NPC 注入上限每轮最多注入多少个 NPC 档案。核心人物多的群像剧可适当调大。
物品注入上限每轮最多注入多少件物品。道具推理或跑团可调大。
新里程碑默认注入模式常驻表示新里程碑默认每轮注入；向量命中表示相关时才注入。里程碑少用常驻；很多时改向量命中。
向量命中里程碑上限向量模式里程碑每轮最多注入多少条。默认 3，避免里程碑淹没普通记忆。
地图地点注入上限命中地点及周边地点最多注入多少处。地图大时保持默认或调小。
启用线索板注入把线索板上的活跃推理注入给 AI。推理线进行中时开启；不想 AI 参考玩家猜测时关闭。
Token 预算本轮 BB-Memory 注入文本的预算参考值。默认 800；上下文紧张时调低。
Token 预算模式resident_unlimited 允许核心/永恒/常驻超预算；strict_total 所有内容共享总预算。日常用常驻不限；上下文爆满用严格总量。
最低相关分普通记忆低于该分数不会进入候选。默认 0.05；误命中过多时调高。
近楼层完整内容窗口来源楼层在最近 N 楼内的记忆优先注入完整内容。默认 6；想更简短可设 0。
注入模板控制最终注入外壳，{{memories}} 是记忆正文占位符。不熟悉 prompt 时保持默认。
升降格与维护
设置代表什么建议
维护模式auto 静默维护，semi 给建议等待批准，manual 完全手动。推荐 semi，避免误删重要线索。
记忆 / NPC / 物品维护阈值数量超过阈值后提醒维护。长篇可调高，但别让列表无限膨胀。
物品积灰未命中轮数物品连续 N 轮未命中后会被视为积灰候选。关键道具多时调大。

记忆升级命中计数瞬时到稳定、稳定到核心需要的净命中数。默认 20，想更快沉淀可调低。

记忆降级未命中计数稳定或核心长期未命中后降级所需计数。默认 20；剧情跨度大可调高。

启用自动备份数据变化后自动防抖备份到聊天元数据。跨设备用户建议开启，超限会跳过。

云端向量槽上限单个角色唯一云端向量槽的大小上限。默认 2048KB；向量很多时可提高。

常见问题

看不到 BB-Memory 设置面板

确认扩展文件夹名是 BB-Memory，扩展已在 SillyTavern 启用，并刷新页面。扩展会尝试挂载到 #extensions_settings2 或 #extensions_settings。

手动提取失败

先检查 AI 自动提取的 API 端点、Key、模型和连接测试。自定义端点必须是 OpenAI 兼容接口，且协议为 http 或 https。

AI 忘记了重要剧情

检查该条是否被归档、是否分数太低、是否超出 Token 预算。可在管理器里升格为核心或永恒，或把相关里程碑设为常驻。

注入太多导致回复变慢

降低最大检索数、NPC/物品/地图上限，或把 Token 预算模式改为严格总量。记忆维护和体检也能减少冗余。

跨设备后语义检索变差

文本备份不内联向量。请在旧设备管理器“存档”页上传云端向量槽，新设备恢复文本后再加载云端向量。

旧 JSON 字段不匹配

v9.2.0 起旧“时间条目”改为 milestones，旧“时间线程”改为 timeline。旧备份可先用 tools/bbmemory-v9.2-save-converter.html 转换。

任何删除、清空、加载存档、批量归档、Agent 写操作前，都建议先导出 JSON 或执行备份。BB-Memory 会尽量给出确认和 toast，但用户侧备份仍是最稳的保险。
